# Preparing an owner care message

Open **Review stay details** to check the dog and stay dates. The dog name, start date, and end date are required; the end date may match the start date but cannot come before it. Phone is optional.

Choose **Prepare owner message** when the details are ready. The form highlights missing or invalid values and moves focus to the first one. Correcting a value clears its message. Pressing Enter in an owner detail field runs the same preparation action. Enter in other controls, or while composing text with an input method, does not prepare a message.

Preparation checks the guest identity before creating the owner care link. It does not send a message. Review and copy the prepared message into the owner’s usual chat yourself.

To review prior stays, open **Other options** and choose **Check Guest History**. This reads history only for the exact Dog ID associated with the selected guest. If the lookup fails, use **Retry Guest History**. Changing the selected guest discards any pending result.
