# Care roster photo delivery

Roster tiles now select a Drive thumbnail rendition from the tile's measured CSS width and `devicePixelRatio`, using 320, 640, 960, 1280 or 1600 pixels. Profile photos and belongings-gallery previews keep the original URL. Non-Drive and non-thumbnail URLs pass through unchanged. If a smaller tile request fails, that image falls back to the original URL once for the current photo.

Repeated rendering of the same photo now leaves the image nodes and their attributes untouched. A real photo change updates each existing image's `src` in place; the edit button remains a sibling and stays connected. Repeated no-photo updates keep the existing placeholder. Hydration, server reads, saved photo records, and upload behavior are unchanged.

The focused unit tests exercise rendition selection from CSS width and device scale and verify arbitrary URLs remain unchanged. Browser tests intercept only synthetic `drive.google.com/thumbnail` requests and record request URLs, fixture response bytes, natural dimensions and decode completion. At a 180 CSS-pixel tile with DPR 1, the synthetic fixture verifies `w320` for the tile and preserves `w1600` for the profile image; the fixture's encoded byte lengths are compared directly. The fixtures use deterministic PNG raster images. These are local fixture measurements, not estimates of live Drive transfer savings.

Run `node --test tests/care-photo-delivery.test.js` and `npx playwright test --config playwright.care-photo-save.config.js`. The browser cases cover both Chromium and WebKit, same-photo zero-mutation reuse, actual-photo replacement, focus/edit-control preservation, and one-shot fallback after a failed small rendition. An actual directory-page fixture additionally verifies that the roster requests only the 320-pixel preview before profile intent, then loads the original 1600-pixel profile preview. A terminal tile failure reveals the existing initials and unchanged updates do not restart the failed request. No production photo or guest endpoint is contacted.
