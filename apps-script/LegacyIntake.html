Legacy Intake Scanner

Reuse a stored intake or upload a new PDF/photo, read it for free in this browser, then review the values before they update Waffle.

🆓 Free OCR — no API key or paid AI provider
Waffle first reads any real PDF text with PDF.js, then uses Tesseract.js locally in this browser for scanned pages and photos. The OCR text is mapped by Waffle's own rules into the existing Care/Profile review workflow. Nothing needs Groq, Gemini or another paid OCR account.

1. Choose the guest & intake form

When opened from a Care profile, the matching stay is preselected. If legacy files already exist, choose the exact stored file and run the free OCR reader without uploading it again.

PDF, JPG/JPEG, PNG and WebP are supported. The free browser reader handles up to 20 PDF pages per intake. Clear, straight photos give the best handwriting OCR. If a handwritten answer is imperfect, you can correct the OCR text before reprocessing it.

2. Processing

Keep this window open. OCR runs on this device; larger scanned PDFs can take a minute or two.
